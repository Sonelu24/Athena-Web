THE AEGIS SHIELD • FORENSIC INCIDENT RESPONSE & THREAT HUNTING

Triaging suspicious artifacts, detecting brute-force attempts in SSH logs, verifying file integrity baselines, dissecting phishing headers, inspecting raw PCAP captures, and defanging threat indicators.

🔐 SSH Auth Log Analyzer ssh
Parse Linux `/var/log/auth.log` or syslog, detect password spraying, dictionary brute-force attacks, invalid user attempts, and attacker IP distribution.
auth.log (default sample)
🛡️ File Integrity Monitor (FIM) fim
Establish SHA-256 baseline snapshots across critical system directories and verify changes to detect unauthorized tampering or backdoors.
📧 Phishing Email Analyzer phishing
Dissect `.eml` / RFC 822 email files, verify SPF/DKIM/DMARC authentication hops, score urgency keywords, and flag lookalike sender domains.
sample_phish.eml (default sample)
🦈 PCAP Threat Hunter pcap
Pure-Python PCAP binary stream parser (zero Scapy/Wireshark required): inspect TCP/UDP packets, extract DNS queries, and detect C2 beaconing.
capture.pcap (default sample)
🔬 Malware Binary Triage malware
Static forensic examination: compute Shannon entropy to detect packed/encrypted payloads, extract suspicious ASCII/Unicode strings, and inspect PE headers.
sample.exe (default sample)
🎯 IOC Extractor & Defanger ioc
Extract IPv4/IPv6 addresses, domains, URLs, CVE numbers, and MD5/SHA256 hashes from incident tickets or files, and defang them for safe documentation.
🕵️ PHP2Shell Webshell Detector php2shell-detect
Recursively inspect web directory structures and web server access logs for webshell signatures (c99, r57, b374k, system, passthru, eval base64).
access.log (default sample)
