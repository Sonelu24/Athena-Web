THE SPEAR • ATTACK SURFACE & VULNERABILITY RECONNAISSANCE

Execute active and passive reconnaissance, discover hidden endpoints, audit security headers, test for exposed credentials, scan dependencies for CVEs, and inspect cryptographic posture.

🌐 Attack Surface Mapper mapper
Crawl target web roots, extract hyperlinks, scripts, robots.txt, sitemap.xml, and discover hidden endpoints and sensitive files.
🛡️ Security Header Scanner headers
Audit HTTP security headers (HSTS, CSP, X-Frame-Options, CORS wildcards) and compute an automated security letter grade (A+ to F).
🔑 Password Breach Checker breach
Query HaveIBeenPwned 800M+ exposed passwords securely using NIST-compliant k-Anonymity SHA-1 hash prefixes (zero plain-text transmission).
📦 CVE Dependency Scanner cve
Parse software dependency manifests (requirements.txt, package.json) and query OSV.dev and NIST NVD for known CVE vulnerabilities.

🎫 JWT Security Auditor jwt

🔒 TLS & Certificate Inspector tls
Inspect SSL/TLS certificate chains, expiration countdowns, Subject Alternative Names (SANs), intermediate CAs, and supported cipher suites.
⚡ PHP2Shell Exposure Auditor php2shell-audit
